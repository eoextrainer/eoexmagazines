# CARTESIENES by EOEX

A single-page editorial kiosk for the CARTESIENES magazine collection.

## Run locally

Open `index.html` in a browser. The site is a static HTML, CSS, and JavaScript project with no build step or runtime dependencies.

## Languages

The interface defaults to French. Use the language selector to switch between French, English, Spanish, Italian, Portuguese, and German. The selected language is saved in the browser. Interface translations are local to the page; magazine issue titles remain in their editorial language.

## Publish

GitHub Pages publishes the site from the `main` branch at the repository root. The deployed site is available at <https://eoextrainer.github.io/eoexmagazines/>.

The EOEX Agency link is active in the footer. EOEX Academy and EOEX Publishing are shown as coming soon until their URLs are provided.
